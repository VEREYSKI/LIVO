🔒 Политика конфиденциальности LIVO

Последнее обновление: 28 сентября 2026 г.

Эта страница описывает, какие данные может обрабатывать LIVO и для чего они используются. Перед публичным запуском проекта текст следует адаптировать под фактический хостинг, аналитику, cookies, базу данных и требования законодательства страны, где работает сайт.

1. Какие данные могут обрабатываться

  • поисковые запросы, которые пользователь отправляет сайту;
  • технические данные запроса, необходимые для работы сервера, например IP-адрес и время запроса — если их сохраняет выбранный хостинг;
  • данные прогресса и настроек — только если в будущем будет добавлена система аккаунтов и сохранения;
  • данные, которые передаются сторонним API при поиске контента.

2. Для чего используются данные

Данные могут использоваться для работы функций сайта, поиска контента, сохранения настроек, защиты сервиса от злоупотреблений и исправления технических ошибок.

3. Сторонние сервисы

Музыкальный поиск LIVO может обращаться к стороннему API. В таком случае запрос и технические данные могут обрабатываться соответствующим поставщиком по его собственным правилам и политике конфиденциальности.

4. Cookies

Если LIVO будет использовать cookies, например для входа, настроек или аналитики, на этой странице необходимо указать их назначение, срок хранения и соответствующие способы управления ими.

5. Хранение данных

Срок хранения зависит от конкретной функции и настроек сервера. В текущей версии музыкальные результаты могут кэшироваться локально в SQLite, чтобы повторные запросы не отправлялись каждый раз.

6. Безопасность

Мы стремимся защищать данные, однако ни один интернет-сервис не может гарантировать абсолютную безопасность. При публикации LIVO следует использовать HTTPS, защищённые секреты API и production-сервер вместо встроенного сервера разработки.

7. Контакты и запросы

Если ты добавишь официальный email проекта, укажи его здесь. Пользователь должен иметь понятный способ задать вопрос о своих данных.

8. Изменения политики

Политика может обновляться при добавлении новых функций. На странице следует указывать дату последнего изменения.

Важно: это шаблон политики для проекта LIVO, а не юридическая консультация. Перед коммерческим или публичным запуском его стоит проверить с учётом применимого законодательства.
