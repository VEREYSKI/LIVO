ℹ️ О LIVO

LIVO — это современный развлекательный и lifestyle-сайт, объединяющий фильмы, игры, музыку, фитнес и челленджи в одном месте.

🎬 Фильмы

Каталог фильмов позволяет искать и просматривать информацию о релизах разных лет, включая фильмы 2000–2026 годов.

🎮 Игры

Раздел игр содержит каталог игр по годам, жанрам и платформам. Есть фильтры по жанрам: RPG, экшен, шутеры, хорроры, гонки, стратегии, выживание и другие.

🎵 Музыка

Музыкальный раздел содержит подборки артистов и динамический поиск через подключённый музыкальный API. LIVO не должен хранить или распространять музыку без соответствующих прав.

🏋️ Фитнес

Раздел помогает подобрать упражнения и тренажёры по общей цели и уровню подготовки. Количество подходов и повторений является общим ориентиром, а не персональным медицинским назначением.

🔥 Челленджи

Пользователь может выбирать фитнес-челленджи разной продолжительности: от нескольких дней до нескольких месяцев.

📅 Дата создания

Сайт LIVO создаётся с 3 августа 2026 года.

💡 Зачем создан LIVO?

Идея LIVO — собрать несколько интересных направлений в одном простом, современном и удобном проекте, который можно постепенно развивать.

🛠️ Технологии

Проект создан на Python с использованием Flask, HTML, CSS и JavaScript. Flask поддерживает маршруты, шаблоны и статические файлы, что подходит для такой структуры сайта. citeturn0search0turn0search1
